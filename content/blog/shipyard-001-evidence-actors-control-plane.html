No flattening all three into "we built it."

Observations can now become claims deterministically

A useful intelligence system needs a boundary between something was observed and the system is willing to assert something based on it.

That boundary is now executable Prolog.

starintel-pro-actors merged deterministic geographic promotion rules that convert eligible geo observations into evidence-backed claims.

The implementation includes:

  • deterministic promotion rules
  • explicit evidence linkage
  • a fixed worker operation
  • worker-boundary tests
  • Prolog semantic tests
  • Nix packaging gates
  • documentation of the promotion contract

The interesting part is not geography by itself. The pattern is reusable.

Instead of asking an LLM whether an observation "sounds strong enough" to become knowledge, StarIntel can encode promotion rules symbolically and make the provenance part of the result.

Evidence in. Rules run. Claim out.

Domain Hunt moved into the actor runtime

Domain Hunt has also been reimplemented as a Common Lisp Sento actor.

That matters because one-off services are steadily being pulled into the same runtime model:

  • mailbox
  • actor lifecycle
  • supervision
  • explicit messages
  • tested boundaries
  • shared infrastructure

The merge was accompanied by hardening and regression coverage rather than treating the actor port as a straight syntax rewrite.

Source: starintel-pro-actors a5567bc9

This is where the actor architecture becomes less theoretical. Every old standalone worker that crosses this boundary gives StarIntel fewer unique failure modes to reason about.

Quasar knows about paid Pro Actors

The next piece is the control plane.

Quasar merged wiring for canonical paid Pro Actors across both its Common Lisp control plane and frontend.

The change touches:

  • the control-plane actor integration
  • actor tests
  • frontend actor management
  • mutations
  • the Actor Hub
  • Pro Actor UI state
  • CI around the Pro Actor integration

So "paid actor" is no longer only a business-model concept sitting next to the runtime. Quasar has a concrete management path for it.

Source: quasar d95157a2

That is an important architectural convergence:

The pieces are starting to meet.

What this does not mean

This does not mean every StarIntel worker is a Sento actor.

It does not mean every evidence type has deterministic promotion rules.

It does not mean the entire billing system is finished.

It means three specific seams are now materially stronger:

  1. Prolog can own evidence-to-claim decisions.
  2. more collection/enrichment logic is moving behind actors.
  3. Quasar can manage the paid actor layer those workers are becoming part of.

That is enough progress to call a Shipyard entry.
